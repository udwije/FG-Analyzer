# LogSikka v6.0.2 implementation note

This package implements the security-critical hardening slice from Phase H:

- H1: firewall-driven syslog allow-list with CIDR extras.
- H2: bounded TCP newline and octet-count frames.
- H3: mandatory SNMPv3 auth/privacy checks after discovery, constant-time digest comparison, engine and time-window checks.
- H8: server-side must-change-password restriction and per-username plus per-IP sign-in lockout.
- H12: regression tests for H1 and H2.

The remaining Phase H items are kept in the roadmap and should not be considered complete by this package. The source was built in an environment without the Go toolchain, so run `go test ./...`, `go vet ./...`, and `govulncheck ./...` on the Go 1.22+ build host before production deployment.
