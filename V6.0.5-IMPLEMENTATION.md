# LogSikka v6.0.5

Implements the first operational part of roadmap H4: HA-aware WAN counter baselines.

The poller now keys continuity to the SNMP authoritative engine identity and also retrieves sysUpTime in the same request as interface counters. A changed engine ID or decreased sysUpTime clears rate baselines before a new sample is calculated. This prevents HA failover or reboot from being interpreted as WAN utilization.

Per-member management-interface polling remains a configuration/topology enhancement and is not enabled automatically in this build.

Before production, run gofmt, `go test ./...`, `go vet ./...`, and `govulncheck ./...` on the Go build host.
