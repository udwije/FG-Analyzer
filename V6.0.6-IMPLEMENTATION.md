# LogSikka v6.0.6

Implements the next roadmap priority, H5 exact WAN volumes.

New WAN samples retain the actual ifHCInOctets/ifHCOutOctets deltas and measured interval. Volume reports use those exact deltas. Historical rows created before v6.0.6 continue to use the prior bounded-gap calculation, avoiding a disruptive history migration.

The schema change only adds nullable columns to wan_samples. HA/reboot baseline resets from v6.0.5 remain active so a failover never produces an exact-delta sample across different counter domains.

Before production, run gofmt, `go test ./...`, `go vet ./...`, and `govulncheck ./...` on the Go build host.
