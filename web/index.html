Measures

The period and filters above (firewall, IPs, users, apps…) apply to the report. Click a value in the result to filter by it; Ctrl+click adds, Shift+click excludes. Click a column heading to sort.

Syslog listener

Firewalls

One FortiGate per line: name, IP address the logs come from. The name is shown on the dashboards (otherwise the FortiGate's own hostname is used). This list does not block anything.

Internal networks

Private ranges (10/8, 172.16/12, 192.168/16, 100.64/10) are always internal. Add any public ranges you use inside your network, one per line. Traffic between internal addresses is "internal only"; anything else is internet traffic. Changes apply to new summaries; history is recalculated by the background summariser.

Network devices (infrastructure)

Management addresses of switches, access points, wireless controllers, UPSs and other network devices, one IP or subnet per line (they may sit in any VLAN). Their own traffic (monitoring, controller tunnels, syslog, SNMP) is moved to the Advanced tab, like routing protocols, multicast and the firewalls' own traffic. History is recalculated by the background summariser.

Site-to-site tunnel interfaces

Branch-to-head-office traffic crosses two firewalls and both log it. A session that arrives over one of these tunnels is counted once, by the firewall it came from (sessions whose incoming interface is the VPN in the log are recognised automatically). One interface name per line, as on the receiving FortiGate.

AI detection

Patterns are matched against the application name and hostname: plain text means "contains", * is a wildcard (*.x.ai). The first matching tool wins. Sites in an AI category that match no tool are listed by domain. Changes apply to new logs straight away.

NPS user mapping (wireless)

A folder means every IN*.log file in it. NPS must log accounting requests (DTS-compliant format recommended) and the wireless controller must send RADIUS accounting with the client IP (Framed-IP-Address). NPS settings apply without a restart.

Staff directory

The nightly export on the NPS server (logsikka-staff-export.ps1) writes staff.csv and computers.csv into the NPS log folder (default C:\NPSLogs), next to the NPS logs. LogSikka reads them whenever they change: joiners appear after the next export, leavers become former staff. The people count then only counts real staff.

Alerts

Rules run every 5 minutes over the summaries. Repeats on the same day update one alert.

Executive summary

The organisation name printed on the summary, and the limits behind its green / amber / red status. The same settings are also in the report itself (Customise > Report settings). A check turns amber or red when the value reaches the limit.

Leave out of the executive summary

Traffic that would distort a management view, for example backups between sites, update servers, a guest network or monitoring. A log matching any line is left out of the totals, the trends, the firewall share and the top lists. One entry per line (or comma separated). Host names: plain text means "contains", * is a wildcard. History is recalculated in the background after you save (about 12 hours of logs per minute); the dashboards are not affected.

Report layout

When Settings > Firewalls lists your firewalls, only those count in the availability check; others are shown greyed as "not monitored".

WAN links (SNMPv3)

The real usage of each internet circuit, read from the firewall's interface counters (like the fgwan tool). On each FortiGate: config system snmp user with security level auth-priv, queries enabled and this server in trusted-host; allow SNMP on the interface this server reaches. Passphrases are kept in the configuration file (readable by the service only) and never shown here.
