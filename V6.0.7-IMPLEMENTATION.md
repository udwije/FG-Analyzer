# LogSikka v6.0.7

Advances roadmap H6 without adding a build-time/network dependency. Domain-like AI patterns now use DNS label-boundary suffix matching, and domain grouping handles the roadmap collision cases plus common multi-label public suffixes used in this deployment region.

The roadmap explicitly calls for the Public Suffix List. This build deliberately implements a conservative embedded suffix set instead of claiming full PSL coverage, because the repository does not currently depend on golang.org/x/net/publicsuffix and this build environment cannot fetch modules. A later dependency-enabled build should replace the embedded set with publicsuffix.EffectiveTLDPlusOne and retain these tests.

Before production, run gofmt, `go test ./...`, `go vet ./...`, and `govulncheck ./...` on the Go build host.
